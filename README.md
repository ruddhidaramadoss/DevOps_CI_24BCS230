# Smart Laundry Service Management System

## Project Description

The Smart Laundry Service Management System is a software project
for managing laundry services, customer orders, pricing, and
pickup and delivery scheduling.

## Main Features

- Customer Registration and Login
- Role-Based Dashboard
- Laundry Service Selection
- Laundry Order Creation
- Automatic Price Calculation
- Pickup and Delivery Scheduling
- Order Confirmation
- Unique Order ID
## Development Status

The customer ordering workflow has been improved for easier
laundry service management.
## Customer Service Feature

Customers can select laundry services, enter the required laundry
details, and schedule pickup and delivery.
